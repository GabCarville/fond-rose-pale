# fond-rose-pale

Un thème rose pâle pour Claude. En mode clair, le fond devient rose pâle et les cartes rose très clair. En mode sombre, le fond devient un rose poudré profond. Le thème s'applique tout seul au début de chaque session, dans l'app de bureau et l'app mobile de Claude (le terminal n'affiche pas de thème).

## Installation

Dans l'app de bureau Claude : clique sur **+** à côté de la zone de message, puis **Plugins**, **Add marketplace** avec `GabCarville/fond-rose-pale`, puis **Add plugin**.

Dans un terminal Claude Code :

```
/plugin install fond-rose-pale --marketplace GabCarville/fond-rose-pale
```

Réponds `y` pour ajouter le marketplace, puis choisis la portée « user » pour l'avoir dans toutes tes sessions.

Depuis un shell :

```
claude plugin install fond-rose-pale --marketplace GabCarville/fond-rose-pale
```
